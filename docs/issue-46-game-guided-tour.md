# Issue #46｜遊戲式功能導覽實作說明

## 架構

- `game-guided-tour.js`：六個步驟設定、狀態控制、版本化儲存、安全回退、目標定位、route／resize／scroll 重定位及鍵盤守衛。
- `game-guided-tour.css`：使用既有語意色與古金色 token 的聚光框、箭頭、羊皮紙提示卡與減少動態效果規則。
- `app.js`：保留既有 hash router，另外發布 `fanatio:route-rendered` 事件及 `FanatioNavigation.openDrawer()`，讓導覽不用複製路由或抽屜邏輯。

導覽不是置中的強制 modal。提示卡會依目標四周可用空間定位；視覺遮罩和聚光標示目標，且目標本身仍可點擊。導覽以事件守衛限制無關背景點擊與焦點逃逸；由於 `inert` 無法排除其中一個子元素，導覽不會把整個 app shell 設為 inert。既有手機抽屜本身的 `inert` 與 `aria-hidden` 管理不變。

## 六個實際步驟

1. 開啟既有全站快速搜尋並指向 `#quick-search-input`。
2. 指向既有生活技能章節連結；手機先以既有抽屜 API 開啟側欄。
3. 進入 `#/life`，指向「採集」分類；實際切換會自動前進。
4. 指向已確認的「日常採集」生活技能清單項目與既有詳情區。
5. 進入 `#/contribute`，指向既有投稿按鈕。
6. 顯示不遮蔽操作的完成訊息與「完成」控制；側邊欄與頂部 `?` 按鈕都能重新開啟。

## 本機儲存契約

| Key | Value | 用途 |
|---|---|---|
| `fanatio-guide-tour-version` | `1` | 導覽內容版本 |
| `fanatio-guide-tour-status` | `completed` 或 `skipped` | 阻止同一版本再次自動啟動 |

讀寫均以 `try/catch` 包裝；儲存不可用時導覽仍可啟動、略過與重播，只是不保存偏好。舊版 `fanatio-tour-v2=done` 只作為一次性的相容性抑制，避免既有訪客重新看到舊導覽升級前的自動提示；「重新觀看功能導覽」仍永遠可用。
