# 官方圖標導入驗收矩陣

本文件記錄核准官方圖標在正式網站元件中的人工驗收範圍。圖標只提供核心圖形；底盤、邊框、焦點、鎖定與狀態由網站 CSS 與文字負責。

## 外觀與配色

每個類別至少檢查下列組合：

- 跟隨系統／亮色／暗色。
- 愛爾琳森林。
- 月光石板。
- 赤紅爐火。
- 紫晶秘典。
- 柔和高對比。

驗收重點：

- 核心圖形與底盤對比清楚，不被固定森林綠污染其他主題。
- 暗色模式不因透明邊緣而消失。
- 高對比模式保留實線輪廓，不只靠色相辨識。
- 圖標載入失敗時仍保留名稱、導覽與既有符號 fallback。

## 裝置與尺寸

- 桌面：1440×900。
- 平板：820×1180。
- 手機：390×844 與 320px 最小寬度。
- 元件顯示尺寸涵蓋 40、44、48、52、56、64、72、80、88px。

驗收重點：

- `object-fit: contain`，不裁切、不拉伸。
- 卡片文字不被圖標擠壓，長名稱可以換行。
- 頁面沒有水平溢位。
- 手機抽屜、篩選、技能展開與回到頁首維持可操作。

## 無障礙

- 同一元件已顯示完整名稱時，圖標使用 `alt=""` 與 `aria-hidden="true"`，避免重複朗讀。
- 鎖定、待補、台版確認與選取狀態仍由文字、邊框或形狀呈現。
- 鍵盤焦點仍落在原本的按鈕、連結與可展開元件，不轉移到裝飾圖片。
- 減少動態效果設定下不增加動畫。

## 自動驗證

執行：

```bash
node scripts/validate-icon-assets.mjs
```

驗證內容：

- 14／4／6／4 與總數 28。
- 生活技能圖標必須對應 `data/life-skill-categories.json` 的正式穩定 ID。
- 穩定英文 ID、公開資產路徑與唯一綁定。
- PNG 簽章、IHDR 尺寸、alpha 通道與 SHA256。
- 禁止 `.blob`、`.bundle`、原始解析資料與私人素材命名。
- `index.html` 已載入 `icon-pilot.css` 與 `icon-pilot.js`。
